# Hardware Setup

## Step 4: Install LED Panels (Optional)

**💡 Customization:** You can install 0-4 LED panels based on your visibility needs.**Choose panels:** Decide how many LED panels to install (0-4 panels)**Attach panels:** Use Phillips screwdriver and screws from tool kit to mount panels on top**Connect wires:** Match panel wires to corresponding machine wires**Secure connections:** Ensure all electrical connections are properly connected and secure

Note: LED panels are optional but provide better visibility and branding.

## Step 5: Install Cup Tubes

**Access dispenser:** Open service door to reach cup dispenser mechanism**Install tubes:** Insert all 4 cup tubes into dispenser assembly**Load cups:** Add 50 approved cups per tube (rim up) = 200 total capacity**Stack properly:** Arrange neatly to prevent crushing or misalignment that causes jams**Close securely:** Close tube lids and service door (prevents dust and maintains hygiene)**💡 Tip:** Proper cup stacking prevents jams.
