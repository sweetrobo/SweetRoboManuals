## Final Steps: Connect Power & Start

<div class="quick-start-content">

<div class="quick-start-text">

<div class="numbered-steps">

<div>
<div>
<strong>Connect power:</strong> Plug NEMA 6-20P power cord into dedicated 220V/20A outlet
</div>
</div>

<div>
<div>
<strong>Power on machine:</strong> Turn on the main power switch
</div>
</div>

<div>
<div>
<strong>Initial startup:</strong> Allow system to initialize (may take 5-10 minutes)
</div>
</div>

<div>
<div>
<strong>Check displays:</strong> Verify all status indicators are normal
</div>
</div>

<div>
<div>
<strong>Wait for ready:</strong> System will indicate when ready for operation
</div>
</div>

</div>

## System Ready Checklist

<div style="background: #d4edda; border: 1px solid #c3e6cb; border-radius: 8px; padding: 1.5rem; margin: 1rem 0;">

### ✅ Confirm All Items:

- [ ] Machine is level and properly positioned
- [ ] All packaging removed from interior
- [ ] Cup tubes installed and loaded (200 cups total)
- [ ] LED panels connected (if installed)
- [ ] Hoppers sanitized and filled with mix (2L+ each)
- [ ] Power connected to 220V/20A dedicated circuit
- [ ] System powered on and displaying normal status
- [ ] First test ice cream completed successfully
- [ ] Temperature displays showing below 5°C (41°F)
- [ ] Internet connectivity established (if using remote features)
